# «Поехали» — сайт планирования и бронирования путешествий

Интерфейс на русском языке. HTML + CSS + React. Светлый сервис в духе Авиасейлс: синий первый экран, белая поисковая строка, оранжевые действия и фотокарточки направлений.

## Что уже работает
- Новый логотип-метка и фирменный синий цвет; название «Поехали» сохранено.
- Главный экран как у Авиасейлс: заголовок, вкладки разделов, поиск «Откуда — Куда — Когда — Пассажиры», оранжевая кнопка «Найти билеты» и белая панель популярных направлений поверх синего фона.
- **Поиск с главной сразу открывает билеты** с выбранными городом вылета, датой и числом пассажиров.
- Выбор направления из списка и **самостоятельный выбор маршрута «откуда → куда»** (14 городов вылета).
- Вкладка **«Карта маршрута»**: интерактивная карта OpenStreetMap/Leaflet с линией маршрута и расстоянием по прямой + кнопка «Дорога в Яндекс.Картах» с реальным маршрутом.
- Билеты: 14 городов вылета, дата, число пассажиров, перерасчёт цены; сборка ссылок вида `aviasales.ru/search/MOW...AER`.
- Отели: заезд/выезд/гости → ссылки на реальный поиск Booking.com.
- Турфирмы: реальные операторы (Библио-Глобус, Level.Travel, Coral Travel, Travelata, Pegas Touristik, Sunmar, Anex Tour) со ссылками на их сайты.
- Избранное, заявки, админ-панель с демо-коэффициентом цен.
- **Тёмная тема** с аккуратным переключателем-тумблером (без эмодзи и лишних подписей). Выбор темы запоминается.
- **Адреса страниц**: `#/dest/sochi` — направление, `#/planner` — планировщик. Страницу можно обновить или отправить ссылкой.
- Адаптив под планшеты и телефоны; все пиктограммы — встроенные SVG, эмодзи в интерфейсе не используются.

## Как открыть
Достаточно открыть `index.html` двойным кликом (работает без сервера).

Пересборка JSX→JS после правок `js/app.jsx`:
```
node build.cjs
```

## Запуск с сервером (нужен для «живых» цен Aviasales)
```
node server.cjs            # http://localhost:5173
```
Сервер раздаёт статику и проксирует `/api/config`, `/api/flights` в API Travelpayouts (Aviasales).

### Чтобы цены обновлялись в реальном времени
1. Зарегистрируйтесь в партнёрской программе Travelpayouts (бесплатно) и получите API-токен.
2. Передайте токен одним из способов:
   - PowerShell: `$env:TRAVELPAYOUTS_TOKEN="ваш_токен"; node server.cjs`
   - CMD: `set TRAVELPAYOUTS_TOKEN=ваш_токен && node server.cjs`
   - или создайте файл `config.local.json`: `{ "travelpayoutsToken": "ваш_токен" }`
3. Откройте сайт через сервер — на вкладке «Билеты» появится зелёный статус «Онлайн-цены Aviasales» и цены будут подтягиваться в моменте.

## Про «настоящую покупку» — важно
Самодельный сайт **не может сам продавать и выписывать билеты/туры**: для этого нужны договоры и платёжные API провайдеров. Поэтому кнопки покупки ведут на реальные сервисы (`Aviasales`, `Tutu.ru`, `Booking.com`, сайты туроператоров) с уже подставленными городом, датой и числом пассажиров — покупка и оплата проходят там.

Цены без токена помечены знаком «≈» и подписью «Демо-цены» — это ориентиры, точные цены всегда на сайте партнёра.

## Структура
- `index.html` — точка входа, фавикон и ранняя установка темы.
- `css/style.css` — оформление, светлая и тёмная темы, адаптив.
- `js/app.jsx` — исходники React-приложения; `js/app.js` собирается командой `node build.cjs`.
- `js/data.js` — направления, отели, рейсы, поезда и партнёрские ссылки.
- `server.cjs` — локальный сервер и прокси цен (необязательно).
- `vendor/` — React, ReactDOM, Babel и Leaflet (работают локально, без CDN).
